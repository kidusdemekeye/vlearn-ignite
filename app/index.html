    How V Learn stays accurate
    1. Claude writes a lesson script. It never draws anything itself.
    2. A validator checks the structure of every lesson: real devices, packets only travel along real cables, every step cited.
    3. Sources must come from a vetted list of RFCs and NIST guidance.
    4. Anything that fails goes back to Claude to fix. If it still fails, you don't see it.
    5. Ready-made lessons are hand-checked. AI lessons are labelled as structure-checked, so you always know which is which.
