# V Learn — 3-minute pitch (Kidus)

Judging weights: Technical 30 · Problem 20 · Market 20 · Impact 20 · Presentation 10

## 0:00 — Hook (problem, 20%)
"In my data structures class here at DSU, the professor explained arrays with American parking garages. I grew up in Ethiopia. That analogy didn't help me, it got in the way.
Networking is worse: it's invisible. Students memorise DNS, TCP handshakes and Wi-Fi association from slides, and none of it sticks.
A picture of the real thing doesn't need the right background."

## 0:30 — Demo (technical, 30%) — SHOW, don't tell
1. Ready-made lesson: "What happens when you visit a website", hit Play. Packets fly in 3D, the tutor voice explains, every step cites the RFC. Point at the packet log ("looks like Wireshark, the tool you'll use on the job").
2. Upload Lab05 Beacon Intro.pdf (from my CSC-420 class). Watch it build an outline and start playing my own class as a 3D video while the rest builds.
   Backup if Wi-Fi/AI is slow: "Try the sample module".
3. Ask a follow-up out loud: "why does it need a handshake?"

## 1:45 — Why it's trustworthy (technical + Mike's process)
- The AI never draws. It writes a script, a validator checks every device, cable and source, and plain code animates it. Anything that fails goes back to the AI to fix, or the student doesn't see it.
- Sources only from a vetted list of RFCs/NIST, or the student's own module page.
- Built the way Mike showed the AI Club: Superpowers spec → plan → tests first → subagent build → independent review → evals. It's all in the GitHub history.
- Numbers: 138 automated tests; 15/15 AI lessons valid on the first try; an independent rater found 11 fully correct, 4 minor imprecisions, 0 wrong; every task independently reviewed and fixed.

## 2:15 — Market (20%)
- First customers: Network+, Security+, CCNA candidates and university students; they already pay for prep.
- Pricing: Free · Student $12/mo · Instructor $29/mo · Schools $8/student/term. The AI is included; students never need an API key.
- Unit economics: a whole module costs ~$0.25 of AI to convert and replays free after that → ~75–85% gross margin.
- Upload-your-own-module is the wedge: instructors and students bring their own content.

## 2:40 — Impact & growth (20%)
- Same engine (script → validator → animator) extends to security, programming, then biology: "see the unseeable".
- Equity: learning that doesn't depend on having the right background.
- Close: "Genio helps you capture the lecture. V Learn helps you see it."

## Likely judge questions
- **What stops hallucinations?** Validator + vetted sources + honest labels; AI never draws.
- **What if the AI is wrong but valid?** The labels say "structure checked, not hand-verified"; next step is instructor review mode and per-protocol citation rules.
- **Cost?** One outline call + one call per lesson; runs on Claude or the Anthropic API via a server route; key never in the browser.
- **Why you?** Cyber student who lived the problem; built it solo in a weekend with a disciplined AI process.
